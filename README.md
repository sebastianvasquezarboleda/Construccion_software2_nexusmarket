# NexusMarket

NexusMarket es una aplicación Spring Boot con un dominio Java para usuarios,
productos, inventario y pedidos.

## Ejecutar

Desde `nexusmarket/nexusmarket`:

```text
./mvnw.cmd test
```

El dominio se encuentra en `src/main/java/application/domain`. Las reglas
principales están cubiertas por pruebas unitarias en `src/test/java`.
